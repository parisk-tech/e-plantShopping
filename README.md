# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is an e-commerce web application for Paradise Nursery where users can browse houseplants, add items to a shopping cart, and manage their cart quantities before checkout.

### Features
- **Landing Page:** Company overview and a "Get Started" button.
- **Product Listing:** Houseplants organized by category with real-time cart updates.
- **Shopping Cart:** Manage item quantities, view totals, remove items, and proceed to checkout.
